                              Offline languages

                              Translate without internet, privately in your browser. Each language is a one-time download (English is included). Models come from the Firefox translation project.

                                Camera text languages

                                Reading text in photos and Basic handwriting need one file per language. Download them ahead to use the camera without internet.

                                  Offline voices

                                  Natural-sounding voices that read translations aloud privately in your browser, also without internet. One voice per language; the first one also downloads the voice engine (30 MB, once).

                                  Kokoro: most natural voices

                                    Piper: one voice per language

                                      Websites

                                      Most websites can’t be read from another site, so translating a website by its link needs a proxy: a small service that fetches the page for this app. Use your own, or this site’s if it has one.

                                      {url} is replaced with the page’s link. Empty: only websites that allow it can be translated.

                                      Make your own free proxy
                                      1. Make a free account at Cloudflare.
                                      2. Open Workers, create a “Hello World” worker, and choose Edit code.
                                      3. Replace its code with the code below, then Deploy.
                                      4. Copy the worker’s address into Proxy address above, followed by ?url={url}.

                                      It only answers this app () and only fetches web pages.
